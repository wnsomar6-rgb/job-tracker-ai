# 📊 Job Tracker AI

Application full stack pour suivre et analyser des candidatures.

---

## 🚀 Fonctionnalités

- Ajout de candidatures (entreprise, poste, statut)
- Backend API avec FastAPI
- Interface web avec Streamlit
- Base de données SQLite
- Dashboard avec statistiques
- Graphiques automatiques
- Score intelligent des candidatures
- Générateur de mails de relance

---

## 🧠 Tech Stack

- Python
- FastAPI
- Streamlit
- SQLite
- Matplotlib
- Requests
