# 🚀 Job Tracker AI

Application full stack intelligente pour suivre et analyser des candidatures.

---

## ✨ Fonctionnalités

- Ajout de candidatures
- Suivi des statuts
- Recherche par entreprise ou poste
- Filtrage dynamique
- Score IA pour chaque candidature
- Dashboard statistique
- Graphique des candidatures
- Générateur de mail de relance
